## 何が書いてあるか

「公開されるのは困る。でも消えるのはもっと困る」——その両方を満たす方法を、
つまずきやすい順に並べています。

- コミットしただけでは、バックアップになっていない理由
- Git と GitHub は何が違うのか
- 非公開のまま保管する方法
- いつ記録し、いつ預けるか
- 患者情報やパスワードを、うっかり入れないための対策
- コマンドを覚えず、AIに日本語で頼んで済ませるやり方

## 注意

Git の仕様や GitHub の画面は変わることがあります。実際の操作は、お使いの環境で確認してください。
また、患者を特定できる情報は、非公開の保管先であっても置かないでください。
